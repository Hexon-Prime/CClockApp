# CClockApp

A command-line clock utility written in C, currently in **public beta** while undergoing testing and active development in Visual Studio Code. Expect frequent updates, bug fixes, and new features as the project moves toward a full release.

## Status
- **Stage:** Public Beta (Work in Progress)
- **Environment:** Developed and tested in Visual Studio Code using C

## Features
- **Overview:** Displays the current time of day.
- **Timer:** Supports custom countdown durations.
- **Stopwatch:** Tracks elapsed time for timing tasks and intervals.
